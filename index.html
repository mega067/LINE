Ejercicio 2: Modelado de Autopistas

Pregunta del Ejercicio

¿Qué tipo de grafo se puede usar para modelar un sistema de autopistas entre ciudades principales donde:

  • a) existe una arista entre los vértices que representan ciudades si hay una autopista interestatal entre ellas?
  • b) existe una arista entre los vértices que representan ciudades por cada autopista interestatal que las conecta?
  • c) existe una arista entre los vértices que representan ciudades por cada autopista interestatal que las conecta, y hay un bucle en el vértice que representa una ciudad si hay una autopista interestatal que rodea dicha ciudad?

Respuestas y Justificación

a) Grafo Simple

Justificación: La regla dice "una arista... si hay *una* autopista". Esto ignora si hay múltiples autopistas. Solo nos importa si existe conexión (al menos una) o no. No se mencionan bucles.

  • No se permiten aristas múltiples.
  • No se permiten bucles.

b) Multigrafo

Justificación: La regla clave es "una arista... por *cada* autopista". Esto significa que si hay 3 autopistas entre dos ciudades, dibujamos 3 aristas entre sus vértices.

  • Sí se permiten aristas múltiples.
  • No se permiten bucles.

c) Pseudografo (o Multigrafo con bucles)

Justificación: Este modelo toma el caso (b) y le añade la regla de los bucles ("...y hay un *bucle*... si... rodea dicha ciudad"). Un grafo que permite tanto aristas múltiples como bucles se conoce comúnmente como pseudografo.

  • Sí se permiten aristas múltiples.
  • Sí se permiten bucles.
