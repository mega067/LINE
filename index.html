Ejercicio 4: Simplificación de Grafos

Pregunta del Ejercicio

Para cada grafo no dirigido de los ejercicios 3-9 que no sea simple, encuentre un conjunto de aristas que se puedan eliminar para simplificarlo.

Recordatorio: Un grafo simple no tiene aristas múltiples ni bucles. Los grafos no dirigidos son 3, 4, 5 y 6. El grafo 3 ya es simple.

Análisis y Simplificación

Grafo 3

Este grafo ya es un grafo simple. No tiene aristas múltiples ni bucles.

Grafo 4

Este grafo es un multigrafo porque tiene aristas múltiples. Para simplificarlo, debemos eliminar las aristas duplicadas.

  • Entre 'a' y 'b': Eliminar una de las dos aristas.
  • Entre 'b' y 'd': Eliminar una de las dos aristas.

Al eliminar estas aristas, cada par de vértices (a,b) y (b,d) tendrá solo una arista, convirtiéndolo en un grafo simple.

Grafo 5

Este grafo es un pseudografo, ya que tiene aristas múltiples y bucles. Para simplificarlo, debemos eliminar las aristas duplicadas y los bucles.

  • Entre 'a' y 'b': Eliminar una de las dos aristas.
  • Entre 'c' y 'd': Eliminar una de las dos aristas.
  • Bucle en 'a': Eliminar la arista que forma el bucle.
  • Bucle en 'd': Eliminar la arista que forma el bucle.

Eliminando estos elementos, obtendríamos un grafo simple con una única arista entre (a,b) y (c,d) y sin bucles.

Grafo 6

Este grafo es un multigrafo. Tiene aristas múltiples. Para simplificarlo, debemos eliminar las aristas duplicadas.

  • Entre 'a' y 'c': Eliminar una de las dos aristas.
  • Entre 'b' y 'd': Eliminar una de las dos aristas.

Al eliminar estas aristas, cada par de vértices (a,c) y (b,d) tendrá solo una arista. El vértice 'e' se mantendría aislado.
